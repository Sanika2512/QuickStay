# QuickStay 🌍

 QuickStay is a full-featured property rental web application inspired by Airbnb.  
It helps users find the best stays, villas, and holiday homes across India.  
Users can explore properties, filter them in real-time, and book the perfect stay.  
Property owners can manage their listings, and administrators have full control over the platform.

---

## Features ✨

### For Users
- **Search Properties:** Quickly search by name, location, or price. Supports dynamic, real-time results.
- **Filter Stays:** Filter listings by type (Beach, Castle, Farm, Rooms, Cities, etc.), price range, and ratings.
- **View Property Details:** Each property has detailed pages showing images, location on the map, nearby attractions, pricing, and amenities.
- **Ratings & Reviews:** Users can give ratings and leave comments.
- **Favorites:** Users can add properties to their favorites for easy access later.

### For Property Owners
- **Add Property:** Owners can list new properties with images, description, location, price, and amenities.
- **Edit Property:** Update property details at any time.
- **Delete Property:** Remove outdated or unavailable listings.
- **View Ratings & Comments:** See feedback provided by other users.

### For Admins
- **Manage Listings:** Admin can edit or delete any property details to maintain platform quality.
- **Monitor Ratings & Comments:** Moderate reviews and ratings to ensure authenticity.

### Advanced Functionalities
- **Interactive Filters:** Real-time filtering by price, type, and rating.
- **Enhanced Search:** Results update based on price, location, and type.
- **Map Integration:** Google Maps shows exact property locations and nearby points of interest.
- **Responsive UI:** Fully responsive and visually appealing frontend, optimized for desktop and mobile devices.
- **MongoDB Database:** All property, user, and admin data is securely stored in MongoDB Atlas.

## Getting Started 🚀

### Prerequisites
- Node.js & npm installed  
- MongoDB Atlas account for database  
- Git installed  

### Installation
```bash
git clone https://github.com/Sanika2512/QuickStay.git
cd WanderLust
npm install

## Setup Environment Variables 🔧

Create a `.env` file in the project root with the following variables:

```env
Mongo_URL=<your-mongodb-atlas-url>
SECRET=<your-secret-key>

## Run Server ▶️
Start the application by running:
npm start
```
Then open http://localhost:8080
 in your browser to see the app.
